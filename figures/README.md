# figures

The manuscript uses one figure, `session_13-48_vs_others.png`, placed as a
two-column `figure*` in Section IV. The notebook produces it, along with four
others the manuscript does not use.

| file | produced by | used in the paper |
|---|---|---|
| `session_13-48_vs_others.png` | notebook, "Look at the samples" | yes, Fig. 1 |
| `samples_per_class.png` | notebook, "Visual sanity check" | no |
| `recall_vs_headroom.png` | notebook, "Plot it" (step 2c) | no |
| `compression_grid.png` | notebook, "Figures" (step 3) | no, cut when the paper was compressed |
| `accuracy_vs_memory.png` | notebook, "Figures" (step 3) | no, cut when the paper was compressed |

A notebook run writes all five into `MyDrive/radar_compression/figures/`.
Copy them here and commit them, so the paper can be built from this
repository alone rather than from a Drive folder that only one person can
reach. They are small, and a figure that cannot be regenerated by a reader is
a figure they have to take on trust.

To build the paper, the figures must sit in a `figures/` directory beside
`paper_main.tex`, which is what `\graphicspath{{figures/}}` in the preamble
expects. On Overleaf that means uploading them into a folder named
`figures`, not into the project root.
